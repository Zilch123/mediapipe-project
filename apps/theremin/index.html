A web page can't open browser settings for you, so the camera permission has to be changed by hand:

  • Chrome / Edge: click the camera or tune icon at the right of the address bar → allow camera → reload the page.
  • Firefox: click the camera icon left of the address bar → remove the "Blocked" setting → reload.
  • Safari: Safari → Settings for This Website → set Camera to Allow.

The camera also only works on http://localhost or HTTPS — not on a file:// URL.
